# Cursed Hollow Moon Guide

Player guide for **Cursed Hollow Moon**, the CobblemonGG Halloween event. It covers every way to earn Spectral Candy, plus the milestone rewards and leaderboard tags.

The whole guide is one file, `index.html`. It needs no build step: open it in a browser, or host it with GitHub Pages.

## Updating the guide

Edit `index.html` and push. If GitHub Pages is on, the live page updates within a minute or two.

- Text and numbers are plain HTML in the `<body>`.
- Colors and fonts are set as variables at the top of the `<style>` block, under `:root`.
- The milestone score checker is the small script at the bottom. If you change milestone scores, update the `data-score` values in the milestones list and the tick positions on the progress bar. Each tick is placed at score ÷ 4,250.
